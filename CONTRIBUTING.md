# Contributing

This is a personal public-source project. The code is here for anyone to
read, use, and fork under the MIT license — but I maintain it solo and
don't have the bandwidth to review or merge external pull requests.

- **Issues** are welcome — bug reports and ideas are genuinely useful.
- **Pull requests** are unlikely to be reviewed or merged. If you want to
  build on this, please fork it.
- No SLA, no roadmap commitments.

If this project outgrows a solo-maintainer model, this policy may change —
but don't wait on that.
